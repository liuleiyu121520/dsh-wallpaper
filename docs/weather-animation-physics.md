# 天气动画物理与规则化改造 — 调研与实现方案

> 需求来源：用户 2026-10-23 提出（雨滴溅射、积雪堆积、雨雪地面积累、天气类型规则化随机、闪电规则化随机、其余天气打磨）
> 现状基线：`src/client.js` 引擎区（KIND_PRESETS + createWeatherEngine），Canvas 2D、零依赖、粒子上限 280

---

## 1. 调研结论

### 1.1 地面积累（雪/雨）

| 来源 | 方法 | 结论 |
|---|---|---|
| p5.js「Falling Snow with Accumulation」| 每列一个高度数组 `snowHeight[]`，雪花落到列上按 size 累加，底边多边形填充 | 2D 高度场是最轻的正解：O(1)/落点、一次路径填充 |
| @zakkster/lite-snow（npm，生产级）| SoA 池化 + 持久堆积高度场 + 融化衰减 + 两阶段生命周期（falling→settled）| 验证「高度场 + 池化 + 融化」在 Canvas 2D 可持续运行 |
| 杨建《基于粒子系统的飘雪景观特效模拟》| 基于高度场的雪花沉积：稀疏时点沉积，堆积后转面沉积；风场用 Boltzmann 驱动 | 允许「点沉积 → 高度场」渐进；风场可简化 |
| Emergent Mind «Snow and Slush»（MLS-MPM）| 材料点法 + 塑性硬化（Stomakhin 2013）| 影视级雪体，每帧网格求解，壁纸场景不适用 |

**结论**：采用 **1D 高度场（按列累积）+ 落点沉积 + 邻列松弛（休止角）+ 融化衰减**。雨不堆高度，只记「湿润度」标量场（用于底部暗湿带与涟漪密度）。

### 1.2 雨滴溅射

| 来源 | 方法 |
|---|---|
| rain-ripple（npm，零依赖）| 落点生成涟漪 + 2–4 个溅射小液滴（上抛、重力回落），`rainCount` 分档（90/150/320），`maxRipples`/`maxParticles` 封顶 |
| p5「AI Raindrop Symphony」| 落点 → 涟漪环 + 一簇 SplashParticle（重力 + 寿命衰减）|
| lumitree 粒子系统教程 | 命中地面 → `spawnSplash` 生成 2–4 个小粒子，vy 向上 + 重力 |
| freefrontend「JS Rain Effects」| Canvas 2D 足够 500–1000 粒子；池化复用避免 GC 抖动；WebGL 仅在数千粒子/折射时必要 |
| pixel-art 4 帧法 | 涟漪环「扩张→消散」节奏，最简可行 |

**结论**：落点产生 **涟漪环（已有）+ 1–3 个溅射液滴（新增池化数组，重力抛物线）**，参数按雨量分档（毛毛雨 1 滴/小涟漪，暴雨 3 滴/大涟漪）。

### 1.3 天气类型演化

| 来源 | 方法 |
|---|---|
| Land of Oz 经典例 / Alaska 四状态 / hsur05 五状态矩阵 | 马尔可夫链：`P(next | current)` 采样，天然产生非固定顺序 |
| SpiceLogic 天气马尔可夫 | 明确「晴很难连续两天」等规则 → 转移矩阵 |

**结论**：**规则约束的马尔可夫链**——12 状态 + 允许跃迁表（禁止 physical 不合理跃迁：晴→暴雪、晴→雷暴）+ **指数分布停留时间**（非固定节拍）+ 雨族强度渐进（drizzle↔rain↔heavyRain 只许相邻档跳变）。

### 1.4 闪电时序

| 来源 | 结论 |
|---|---|
| Wiley 2008 雷电定位网统计（Lebanon storm）| 闪电到达间隔 **非独立泊松**（K-S 检验拒绝指数分布），呈簇状；强活动期接近对数正态/复合泊松 |
| 专利 CN117056760A | 用**非齐次泊松过程**（时变发生率 f(t)）建模雷电 |
| 无线电噪声统计研究 | 复合泊松 + 重叠（多次回击）更贴近实测 |

**结论**：**非齐次泊松**——慢变活动包络 `activity(t)`（双正弦 + 随机游走）调制到达率；每次雷击 1–3 次回击（100–250ms 内）；自然产生「密集簇 + 长静默」，删除现有 1.5–4s 固定间隔调度。

## 3. 实现思路

### 3.1 地面系统（引擎内新分区 `ground`）

```
ground = {
  cols: number,            // 列数 = ceil(width / 10)，上限 256
  snow: Float32Array,      // 每列积雪高度（px），上限 28
  wet:  Float32Array,      // 每列湿润度 0..1（雨），slow decay
  hail: Float32Array,      // 冰雹地面积粒（小颗粒计数），快速融化
}
```

- **沉积**：粒子落地（y ≥ h - snow[col]）时按 `preset.deposit` 系数累加到对应列；`col = clamp(floor(x / colWidth))`
- **休止角松弛**：每帧一次邻列平均（`snow[i] = max(snow[i], (snow[i-1]+snow[i+1])/2 * 0.85)` 的轻量变体），避免尖刺
- **融化**：无雪 kind 时 `snow -= meltRate(晴 1.2px/s、雨 2.0px/s、其它 0.4px/s) * dt`；湿地按 `wet -= 0.15/s`
- **渲染顺序**：背景渐变 → 湿地条带（底部，`wet` 调制 alpha）→ 积雪折线填充（平滑 + 竖向渐变：底部亮白）→ 涟漪 → 粒子 → 闪电/泛光
- **强度联动**：沉积系数随 `effectScale` 与粒子数缩放 → 「雪量大小动态变化」

### 3.2 溅射系统（池化 `splashes`，上限 160）

- 雨类粒子落地：`spawnSplash(x, height, intensity)` 生成 1–3 个液滴 `{x,y,vx,vy,r,life,ttl}`，`vy ∈ [-2.6,-1.2]`，重力 `+0.12/frame²`，寿命 220–380ms
- 涟漪参数按强度分档（毛毛雨 maxR 3–5px、暴雨 8–12px），沿用现有 24 条上限（按暴雨调高到 40）
- 毛毛雨也生成 1 个小液滴 → 「淅淅沥沥」

### 3.3 天气导演（规则约束马尔可夫）

```
状态：12 kind
允许跃迁表（示例）：
  clear     → cloudy(0.7) / wind(0.12) / dust(0.08) / haze(0.1)
  cloudy    → clear(0.35) / drizzle(0.25) / fog(0.15) / wind(0.1) / snow(0.15)
  drizzle   → rain(0.5) / cloudy(0.35) / drizzle(0.15)      // 强度渐进
  rain      → drizzle(0.3) / heavyRain(0.4) / cloudy(0.3)
  heavyRain → rain(0.45) / thunderstorm(0.35) / cloudy(0.2)
  thunderstorm → heavyRain(0.6) / rain(0.4)
  snow      → cloudy(0.5) / snow(0.5)
  fog/haze  → clear(0.4) / cloudy(0.6)
  wind      → clear(0.5) / cloudy(0.5)
  hail      → thunderstorm(0.7) / snow(0.3)
  dust      → clear(0.6) / wind(0.4)
禁止跃迁：clear→heavyRain/snow/thunderstorm/hail、snow→clear（必须先经 cloudy）等
```

- **停留时间**：指数分布，均值按状态给（动态演示模式 40–120s；真实天气接入时不启用导演）
- **接线**：预览下拉新增「动态演化」选项；导演用独立 `directorStore` 驱动 `syncEngine`，**不写 localStorage**，不污染用户的预览选择
- 真实天气模式（跟随 API）保持现状，不受导演影响

### 3.4 闪电（非齐次泊松）

- `activity` 慢变包络：`0.25 + 0.2*sin(0.00021t) + 0.15*sin(0.00057t+φ) + 随机游走`（限幅 0..1）
- 每帧：`p = lambdaBase * activity * dt`，`lambdaBase ≈ 0.18/s`（暴雨闪光同理用 activity 调制，替换现有 `Math.random() < dt*0.00025`）
- 一次雷击：1–3 次回击，间隔 100–250ms，每击重画折线路径 → 自然「连闪」；静默期由 activity 低谷自然产生
- 删除 `nextStrikeAt` 固定调度

### 3.5 其余天气打磨

| kind | 追加 |
|---|---|
| clear | 顶部日晕（径向渐变，isDay 时）、光尘视差分层 |
| cloudy | 远/近两层云影（不同速度与尺寸）+ 密度慢变 |
| fog | 2–3 层雾堤（不同速率、呼吸相位错开）|
| haze | 雾堤 + 浮尘点 + 底部土黄湿带 |
| wind | 少量「落叶」粒子（旋转 + 翻滚），保留风线 |
| hail | 地面积粒（`hail` 列，快速融化）+ 弹跳（已有）|
| dust | 密度波 + 地面浮尘带 |
| thunderstorm | 雨 + 闪电簇 + 阵风弱调制 |

### 3.6 性能与降级

- 主粒子上限 280 不变；溅射池 160；地面列 ≤256，渲染每帧一次折线填充 + 一次条带填充
- 热路径零分配（池化对象、TypedArray）
- `prefers-reduced-motion`：静态背景 + 当前地面状态快照，无动画
- 模式切换：地面积累**保留**（这是「随时间推移堆积」的核心）；切到 system 或 dispose 时清空

## 4. 验收对照

| 需求 | 验收点 |
|---|---|
| 1 雨滴落地溅射 | 小雨/中雨/暴雨都有涟漪 + 液滴；暴雨明显更密更大 |
| 2 积雪动态 | 雪量越大积累越快、越厚；切到晴/雨后缓慢融化 |
| 3 雨雪地面积累 | 连续运行 2 分钟可见雪堆；雨形成底部湿痕 |
| 4 天气类型规则随机 | 「动态演化」模式下 10 分钟内的种类序列符合跃迁表；无固定循环 |
| 5 闪电规则随机 | 出现「连闪簇 + 长静默」，非等间隔 |
| 6 其余天气完善 | 雾霾/风/沙尘/冰雹/晴/多云各有可辨识的补充效果 |
